# Overview board poster images

Save your two flyer images here with these exact filenames:

| File | Used for |
|------|----------|
| `notable-alumni-nominations.png` | Notable Alumni call for nominations (Overview ad) |
| `fun-run-2026.png` | 6th Alumni Homecoming Fun Run (Overview ad + Events poster) |

The app loads them from `assets/ads/…` on the site. After adding files, refresh **Overview** and **Events** to see the full posters.

Optional: run `supabase/seed-community-announcements.sql` in Supabase to store the same content in the database (for editing in Admin).
